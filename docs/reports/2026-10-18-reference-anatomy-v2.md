# 参考片解剖 v2：《什么是诱饵效应》

日期：2026-10-18。取代 `2026-10-17-spongebob-reference-anatomy.md` 中关于节奏和转场的结论。那份报告用较高的场景检测阈值测出"13 个镜头、平均 13.8 秒、只有硬切和 4 帧叠化"，这是错的：背景板全片不变，而真正在变化的舞台画面只占画面中间一块，变化量达不到阈值。

方法：320 px 宽，场景阈值 0.012，相隔不到 0.5 秒的变化合并为一次；然后逐个查看每次变化前 0.1 秒到变化后 0.8 秒的帧（每秒 10 帧）。分析帧在 `target/ref/events-*.jpg`。

## 1. 节奏

| 量 | 值 |
| --- | --- |
| 画面变化 | **67 次 / 179 秒** |
| 变化间隔 | **中位 2.5 秒**，平均 2.7 秒，基本一句台词换一次画面 |
| 单次变化本身 | 0.5–0.7 秒的动画（不是 4 帧叠化） |

## 2. 画面单位：一拍一张完整的场景卡片

固定背景板（虚化的比奇堡天空加草地）上，每一拍放**一张完整的小场景插画**：人物、家具、写着中文的牌子和对话气泡画在一起。卡片位于画面中间略偏右，宽度约占一半，下沿落在草地上，大约在画面高度的 80% 处。画风是干净的绘本线稿风，比海绵宝宝动画本身更简洁。信息（价格、名称、标注）都画在卡片里，不单独飘在空中。

镜头类型：

| 类型 | 例子 |
| --- | --- |
| 场景 | 蟹老板站在柜台后，柜台上立着两块套餐牌 |
| 物件特写 | 托盘里的汉堡和汽水，旁边是"基础套餐 10 贝壳"的牌子 |
| 信息图 | 三块牌子，中间那块被圈出，标着"多余选项"和红叉 |
| 反应 | 只有蟹老板加一个表情气泡 |
| 对比 | 左右两组，中间弯箭头，写着"彻底扭转" |
| 分格 | 2–3 个分格依次展开 |
| 隐喻 | "进阶套餐 16 贝壳"的牌子挂在鱼钩上，表示诱饵 |
| 数据 | 柱状图的柱子依次长出来 |

## 3. 转场：有语义的动作

出画方都会动着离开（下沉、侧滑出画、缩小），入画方：

| 转场 | 用在什么时候 | 例子 |
| --- | --- | --- |
| 原地叠化 | 同一地点，只是换人或时间推移 | 3.9s，16.7s，41.3s |
| 从下方升起 | 引出新物件、价格 | 5.5s，9.8s |
| 从上方掉落 | 新人物或新情况登场；隐喻物垂下 | 14.4s，21.4s，116.6s（鱼钩） |
| 从右 / 从左滑入 | 换地点、换视角、对比的另一边 | 26.5s，28.3s，36.5s，37.9s |
| 由小放大 | 强调、结论、数据 | 24.7s，30.4s，46.3s |

## 4. 开头和结尾

- **开头（0–1.3 秒）**：黑底，做旧红字带灰色重影，"什么是诱饵效应"逐字打出，约 0.7 秒打完；停顿后淡出，第一张卡片从暗处放大进场，台词从 1.4 秒开始。
- **结尾（约最后 10 秒）**：黑底，白色书法字随口播一句一句出现，每句从中间向两边展开，停留 1 秒多后淡出。

## 5. 文字

- **字幕**：圆润的手写粗体（接近站酷快乐体），白字加黑色粗描边，单行，居中，位于画面底部（中心约在画面高度的 90% 处）。
- **画内文字**：画在牌子和气泡里，属于插画的一部分。

## 6. 对配方的影响

见 `extensions/builtin/spongebob-koubo/recipe.json`（v4）：

- 镜头词汇 `shots` 和转场词汇 `transitions` 写在配方里，分镜模型逐拍选择并说明理由；
- 节奏约束是每拍 1.6–6 秒，目标 2.2–4 秒，同一转场最多连用 2 次，至少 3 种镜头；
- 卡片动效在 `motions/cards.json`；
- 规则审片的 `maxHold` 为 6.5 秒。
