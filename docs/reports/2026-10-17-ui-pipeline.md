# UI 与成片基础管线：手动验收清单

日期：2026-10-17。本轮整理了项目结构，修复预览窗遮挡、AI 入轨丢片段等问题，并把「AI 成片」重做为编辑器右侧的停靠面板。下面按验收顺序列出要看的点。

## 0. 准备

1. 关闭正在运行的 TO DO。
2. 在仓库根目录执行 `.\run.ps1`。原生预览宿主的源码比旧的 `preview_host.exe` 新，脚本会先重新编译它，再启动软件。

## 1. 项目结构

- 根目录只保留工程文件：删除了临时目录 `tmp*`、`tmp_app_*.txt` 和 `native/*.obj`。
- 花字参考图移到了 `docs/assets/`。
- 已完成的旧计划移到了 `docs/archive/`。
- `native/build/` 下只留 `bin/` 和本轮的 `clip/`。
- 代码方面：
  - 成片面板拆成 `todo_ui/src/widgets/production/{form,card,content}.rs`。
  - AI 设置的装配代码从帧循环移到了 `todo_app/src/runtime/ai_settings.rs`。
  - 配音时间轴与字幕切分原来在 bridge 和成片用例里各写了一份，现在统一由 `todo_production` 的 `voice::speech_timeline` 和 `subtitles::timeline_cues` 提供。

## 2. 弹窗不再被预览盖住

- 在素材库靠右的条目上右键，菜单伸进预览区域时应完整可见。预览窗会按菜单形状留出空洞。
- 下拉框、右键菜单和悬停提示经过预览区域时都应可见。
- 打开「工程设置」「AI 设置」「导出」这类整屏弹窗时，预览窗应暂时隐藏。

## 3. 深色主题

所有输入框和下拉框都应是深色底，包括 AI 设置、工程设置和成片面板里的。之前系统使用浅色主题时，这些控件会变成白底。

## 4. AI 设置

- 打开设置时只读取模型列表（`/v1/models`，免费），不再自动发送计费的对话请求。
- 点「测试连接」后，才会发送一条极短的对话请求。结果直接显示在弹窗里：
  - 成功显示绿色；
  - 失败显示红色，原因用中文说明，例如「Key 无效或已过期」「账户余额不足」。
- 弹窗里不再显示服务返回的原始 JSON 或 `Auth` 这类内部类名。

## 5. AI 成片面板（右侧「属性 / AI 成片」标签页）

- 点工具栏的「AI 成片」或右侧的标签都能切换到面板。面板停靠在右侧，不遮挡预览，生成时可以同时看着时间轴。
- **新建成片**：
  1. 选择风格（卡片上标明「可用 / 需要 Key」）；
  2. 粘贴文案（显示字数）；
  3. 调整基本设置：音色可以选常用音色，也可以填自定义音色 ID；其余参数收在「更多设置」里。
  - 「开始生成」不可用时，按钮下方会写明原因。
- **任务卡片**：
  - 显示标题（文案开头）、风格名和一句话状态，例如「正在生成画面素材（5/12）」。
  - 显示进度条和阶段标签：分段 → 配音 → 字幕 → 分镜 → 画面 → 合成 → 入轨，每项带 n/m。
  - 失败项会写明是哪一部分失败（例如「第 2 段配音没有完成」），并给出对应操作：
    - 「重试」；
    - 可能已扣费的请求先要求「确定重试」；
    - Key 或余额问题显示「打开 AI 设置」。
  - 卡片上不会出现任务 key、`g1/e7` 或 `builtin.xxx` 这类内部标识。
- **查看和修改内容**：
  - 按段展开后可以改文案，然后点「保存文案」。
  - 每个画面显示缩略图和状态。点开画面后可以：改描述后重画、再来一张、用自己的图片、点选候选图。
- **你现有的 untitled 工程**：
  - 上次那份成片的「配音」和「黑板底」被误记成了「用户删除」。
  - 打开工程后，卡片上会提示「你从时间轴删掉了 2 个片段」。点「放回删掉的 2 个片段」，黑板底会回到时间轴，阶段显示「入轨 9/9 · 已完成」（已在副本上验证）。

## 6. 成片管线（需要联网，会产生少量费用）

建议用两三段、合计约 200 字的文案做一次「黑板手绘」。需要观察：

1. 配音和字幕先入轨，黑板底随后入轨，然后各块黑板的书写画面按顺序逐批入轨。整个过程中卡片的阶段数字持续推进。
2. 素材库里新生成素材的名字可读，例如「第 1 段配音」「黑板底」「画面 · 存钱罐」，不再是哈希文件名。旧工程里已经登记的素材名不会改。
3. 生成过程中保存或继续编辑，然后关闭并重新打开工程，已入轨的片段不应丢失。
4. 删掉一个 AI 片段后，它不会自动回来；可以用卡片菜单「放回删掉的片段」恢复。

## 本轮修复的问题与原因

| 问题 | 原因 | 修复 |
| --- | --- | --- |
| 弹窗被预览盖住 | 预览是另一进程的顶层窗口，始终压在编辑器之上 | 新增 `clip` 协议命令：egui 浮层压到预览区域时，原生窗口用 `SetWindowRgn` 在对应位置挖空 |
| 重开工程后 AI 片段丢失 / 黑板底没入轨 | 入轨后需要保存工程；如果这时恰好有一次保存正在进行，这次保存会被直接跳过。成片记录里已经写了「已入轨」，重开工程时这些片段就被当成用户删除 | 等当前保存完成后补存一次（`Productions::resave`）；对账时，如果片段在时间轴上但记录里没有，就补登记并清除错误的「已删除」标记 |
| 卡片一直停在「入轨 8/9」 | 对账只在片段有变化时才写记录 | 同上，补登记 |
| 打开 AI 设置就扣费 | 打开设置时会自动发送真实的对话测试 | 打开时只读取免费的模型列表；对话测试只在用户点击「测试连接」时发送 |
| 输入框是白底 | 系统为浅色主题时，egui 改用自带的浅色样式 | 固定使用深色主题 |
| AI 服务启动失败时面板为空，没有任何说明 | 启动错误被直接丢弃 | 面板里显示失败原因 |
