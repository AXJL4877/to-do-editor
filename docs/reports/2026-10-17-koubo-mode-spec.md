# 海绵宝宝口播：可执行模式规格（v1）

更新：2026-10-17。依据：参考片《什么是诱饵效应》逐帧解剖 + 上游 `studio.spongebob-koubo` 工作流 + 本次成片实测。
本文是"拆得更细"的下钻结果：把镜头拆到元素槽位，把台词拆到逐字时间。

## 1. 最小单元：一镜 = 五个槽位

| 槽位 | 内容 | 是否必需 | 版式 |
| --- | --- | --- | --- |
| `plate` | 海底背景板 | 是 | 全画幅，全片复用同一张 |
| `stage` | 舞台矩形（角色所在的小场景） | 可选 | 居中偏左，宽 ≈45%，下沿 ≈72% |
| `cast` | 角色 1–2 个 | 是 | 舞台内，脚底贴舞台下沿 |
| `props` | 道具 0–3 个（牌、钟、贝壳、券） | 按语义 | 角色左右，与台词提到的东西同侧 |
| `marks` | 手绘标注 0–2 个（红叉、箭头、VS、圈选） | 可选 | 覆盖在 `props` 上 |
| `type` | 文字：字幕（必）+ 牌面字 + 批注字 | 是 | 见 §4 |

配额纪律：**一镜最多 5 个可见元素**，超了就说明该拆镜。参考片 13 镜里，单镜元素数 2–4。

## 2. 时间结构：镜头跟着句群走，字幕跟着字走

| 量 | 参考片实测 | 生成规则 |
| --- | --- | --- |
| 镜头时长 | 4.4 / 6.8 / 7.5 / 8.3 / 10.2 / 13.9 / 15.1 / 20.9 / 21.0 / 27.5 / 36.6 s | **句群时长**（1–3 句），不按总时长均分 |
| 字幕条数 | 60 条 / 13 镜 ≈ 4.6 条每镜 | 每句再按标点切 ≤14 字 |
| 字幕时长 | 中位 2.16 s | 逐字时间戳首末 + 0.18 s 尾 |
| 字幕间隔 | 0.2–0.8 s（跟着换气） | 相邻条至少留 0.06 s |
| 镜头/字幕比 | 1 : 4.6 | 一镜内字幕连续推进，画面不动 |

镜界判定：在相邻两句的**中间点**切镜，而不是句末——避免切点压住字。

## 3. 转场矩阵

| 场景 | 处理 | 实测依据 |
| --- | --- | --- |
| 同场景换角度 | 硬切（1 帧） | 149.4 s 处峰值帧差 15.6、仅 1 帧 >50% |
| 换场景 | 4–5 帧叠化（0.13–0.17 s） | 37.93 / 95.60 s 处 4–5 帧渐变 |
| 元素出现 | 0.2–0.3 s 入场（pop/rise/stamp） | 60.0 s 处 8 帧渐变 |
| 段落切换 | BGM 换段 + 画面换场 | 全片 3 段 BGM |

**不需要**：推拉摇移、光效转场、粒子。参考片一个都没有。

## 4. 排版数值（1080p）

| 元素 | 参数 |
| --- | --- |
| 字幕字号 | `fontSize = 0.062`（≈67 px，字面高 ≈62 px） |
| 字幕位置 | `y = +0.40`（中心 0.90，底线 0.928），`x = 0` |
| 字幕样式 | 白字 + 黑描边 0.12 em + 4% 投影 |
| 牌面/批注字号 | `0.050–0.055`，金色 + 黑描边 0.14 em |
| 结尾标题 | `0.13`，白色重衬线，居中 |

## 5. 音频

| 项 | 参考片 | 本片 |
| --- | --- | --- |
| 口播 | 克隆音色，语速 +16% | `seed-icl-2.0` + `S_RksT6Z6g2`，`speech_rate=16` |
| 整体响度 | −11.7 LUFS / LRA 1.9 | 导出后统一 −16 LUFS（编辑器默认） |
| BGM | 3 段，−18 dB 左右 | 3 段，gain 0.22，进出淡入淡出 |
| 静音段 | 0 | 0（BGM 全程垫底） |

## 6. 生成顺序（渐进入轨）

```text
文案 → TTS（克隆音色，拿逐字时间）→ 句子时间轴
     → 句群 → 镜头表（每镜 1 张画面 + 0–3 个文字层）
     → 字幕（逐字对齐）→ 牌面/批注文字 → BGM 三段 → 导出
```

每一步都用**上一段的真实时间**，不允许"总时长 ÷ 条数"这类均分。

## 7. 验收指标

| 项 | 目标 |
| --- | --- |
| 镜头数 | 句群数（本片 9） |
| 字幕条数 | 句子切分结果（本片 40±5） |
| 字幕首字对齐误差 | ≤ 0.12 s |
| 字幕末字提前量 | ≤ 0.25 s |
| 单镜元素数 | 2–5 |
| 背景一致性 | 全片同一张 plate，SSIM > 0.9 |
| 响度 | −16 ± 2 LUFS |

## 8. 与旧扩展的差别（一句话）

旧 worker 是"均分时长 + 每镜一张 AI 图 + 占位卡"；本规格是"句群定时 + 固定槽位 + 逐字字幕"。
前者产出幻灯片，后者产出节目。
