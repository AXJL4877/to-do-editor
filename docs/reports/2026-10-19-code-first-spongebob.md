# 海绵宝宝口播 v5：以代码为主的稳定流程

日期：2026-10-19。需求来自 `docs/一些新的想法.txt`（内置 Agent 先放一边；一句一镜；开头红字、讲故事背景板加元素动效、升华黑底黄字；渐进入轨；生图 300 秒超时重提）。你的补充决定：不做审片；没回来的图片位置空着、不放占位图；升华可以放在片中，但总时长不超过全片 20%；重提最多 3 次；黄字和元素动效由我设计；有些镜头放不止一个元素。

## 1. 流程

```
文案（给定，或按主题生成）
 → 配音（逐字时间）            → 立即入轨：配音、BGM、片头红字
 → 字幕断点 + 代码断句：一句一镜（短于 1.2 s 并入相邻句，长于 6 s 在字幕断点拆开）
 → LLM 一次调用给每镜打标签：story / sublime、主卡片描述、0–2 个附加元素、少数特殊动效
 → 代码逐镜校验：无效回答只退回这一镜；升华超过 20% 时从片中往前改回讲故事（保留结尾）
 → 立即入轨：背景板 / 黑底、字幕（升华镜头不出字幕）、升华黄字、素材库元素
 → 所有图片一次性提交；每张回来就裁边、立即入轨（失败 3 次的卡片用这一镜的角色素材图）
```

LLM 只管"画什么"。结构、时间、版式、入轨顺序都在 `worker/main.py` 和 `recipe.json` 里。

## 3. 版式（代码固定，坐标以画布为单位）

- 地面线：画面高度 0.8 处。实物、角色、生成元素都站在地面线上。生成的图片先按不透明像素裁边，所以脚底就是图片底边。
- 没有附加元素：主卡片居中略偏右（x = 0.03），高 0.56，最宽 0.66。
- 有附加元素：主卡片左移（x = −0.17），高 0.5，最宽 0.52（右边缘约在 x = 0.09）。元素放在右侧槽位：1 个在 x = 0.30；2 个在 x = 0.21 和 0.40；每个最宽 0.17，所以不会压到主卡片。
- 元素高度按类型：角色 0.42，道具 0.30，生成物件 0.32，悬浮符号（问号、灯泡、箭头、红叉）0.20，悬在 0.42 高处。
- 层级：元素在主卡片上面的轨道（lane 2、3），主卡片在背景板上面。
- 时间：元素在台词说到 `at` 那几个字时出现（用配音的逐字时间）。不早于主卡片落定（0.45 s 或入场动效的 80%）；两个元素之间至少隔 0.3 s；至少显示 0.7 s；在下一张卡片开始转场进来之前退场（同轨转场以切点为中心）。

- 渐进入轨：配音、BGM、片头约 20 s 入轨；字幕、背景、升华字和素材库元素约 40–60 s 入轨；生成的图片从约 75 s 起逐张入轨。
- v9 有一张卡片发了 3 次，724 s 才回来：属于 97 张历史样本里超过 300 s 的那约 3%（历史中位数 48–86 s）。
- v8 暴露并已修掉的问题：
  - 上一镜的元素和下一张滑入的卡片叠在一起 → 元素提前到转场开始前退场。
  - LLM 几乎每镜都指定动效，还连续用了两次"掉落" → 由它指定的动效最多占约三分之一的镜头，且不许和上一镜相同，其余用随机。
  - 每镜只放 1 个元素 → 提示词要求至少四分之一的镜头放 2 个。
  - 升华字断行断在词中间 → 改为在句号或逗号处断行，离中间太远时才从中间断。
- 用同样的请求重跑 v9：只用 6.8 s，全部命中缓存，没有再付费（修复指纹之前重跑会重新生成并付费）。任务日志合并了 63 条重复记录，备份在 `target/agent/ai-tasks-backup-1019`。

## 6. 没做 / 待定

- 审片：按你的要求暂不做。重画某一张图可以填参数 `redraw`，例如 `shot/3/card:1` 或 `shot/5/el/0:1`。
- 版式是固定槽位，不识别图片内容，见第 3 节。可以改进的方向：按卡片的透明区域找空位；让符号贴到相关物件上（例如红叉盖在牌子上）；左右镜像版式，增加变化。

## 7. 补充（同日下午）：按关系排版、1 分半实测

### 排版：模型说意图，代码算坐标，评分挑方案

起因：固定槽位把汉堡放在右下角，右边只留了 2%（截图 `Snipaste_2026-10-19_13-46-32.jpg`）。

- **模型只描述关系**（`prompts/shots.md`）：每个元素给 `relation`（`beside` 站在旁边 / `front` 压在主卡片边缘前面 / `above` 飘在头顶 / `on` 盖在另一个元素上）、`target`（挂在哪个元素上）、`size`（tiny / small / medium / large，相对于角色身高）、`side`（只有故事里有明确方向时才填）。模型没填的项用默认值：素材库里的符号默认飘在上方，其余默认站在旁边，大小取 `library.json` 里的 `size` 字段。
- **代码按真实形状排版**（`worker/main.py::compose`）：每张图按不透明像素裁边，并算出视觉重心。主卡片和站在地面上的元素组成一行，间距统一。飘在上方的元素挂在目标的包围框上方，盖上去的元素居中压在目标上。整组按视觉重心居中，左右至少留 6% 边距。太宽时整组等比缩小。
- **候选打分**：把模型没定的项（元素放左边还是右边、两个元素谁在前、主卡片是否缩小一档）全部排列一遍，用规则打分：边距、重心偏移、意外重叠、缩小程度，以及这一镜偏好的镜像方向（相邻的讲故事镜头交替偏左、偏右，保证有变化）。取分最低的方案，随机种子固定，重跑结果一样。
- **入轨方式改为逐镜**：一镜的所有图片（主卡片和生成的元素）都回来以后，再一起排版、一起入轨。素材库元素不再提前单独入轨。
- 用 v9 的缓存对比新旧排版（`target/prod/herd-v9.mp4` 和 `target/prod/herd-v9-layout.mp4`），没有新的生图费用：符号挂在主体上方，道具贴着主体、按统一间距排开，整组居中，汉堡缩到合理大小，元素也会出现在主体左边。

### 1 分半实测（`v10-confirm`，主题：什么是确认偏误）

- 48 镜（41 镜讲故事、7 镜升华，升华占 13.6%），41 个附加元素。模型主动用了 `on`（红叉盖在垃圾桶或牌子上）、`above`（放大镜、问号）、`front`（盘子、纸条）。
- 全程 716 s：配音 65 s；配音、BGM、片头 85 s 时入轨；字幕和背景 166 s 时入轨；第一镜画面 219 s 时入轨。
- 成片 **138 s，而不是 90 s**。原因：配方假设每秒念 6.6 字，这个音色在 +16% 语速下实测是 **4.6 字/秒**（v8、v9、v10 三支一致；之前两支 30 秒的片子也因此长到了 37–40 秒）。已改为按语速换算（`speech.charsPerSecondAtRate0 = 3.97`），文案超过上限 8% 时会让模型删减一次。这个修正还没有跑实测验证。
- 升华黄字单行上限从 12 字提到 16 字（超出时字号自动缩小），避免没有逗号的句子在词中间断行。

### 注意

你的编辑器（`target\debug\todo_app.exe`，10:48 启动）打开 v9-herd、v10-confirm 时，会在我导出之后把它内存里的版本存回 `project.json`，所以这两个工程文件不一定是命令行的输出。成片以 `target/prod/*.mp4` 为准。编辑器和命令行共用 `cache/ai/tasks`：建议重启一次编辑器，让它读取迁移后的任务日志。

## 8. 补充（同日傍晚）：元素减量放慢、升华重做、重叠修正

起因：元素动效太多太快，来不及看；黄字升华太简陋；仍有元素不合理重叠。

### 元素：少一点、慢一点

- 只有够长的镜头才放元素：1 个元素要求镜头至少 2.4 s，2 个至少 3.4 s（`elements.minShot`）。
- 卡片落定后再等 0.2 s（至少 0.7 s）才出元素；两个元素之间至少隔 0.9 s；每个元素至少停留 1.3 s。台词的词来得太晚时，元素稍微提前出现，保证停够时长；整个镜头放不下才去掉。去掉的生成元素不会去画，也不花钱（`calm_elements`）。
- 元素动效整体放慢约 35%（落地 0.74 s、弹出 0.61 s、盖章 0.43 s……）。
- 提示词改成"只给大约三分之一的讲故事镜头，宁少勿多"。

### 升华：虚化画面打底，红字压在上面

- 每镜升华生成一张能代表这句话的单独物件图（不含文字）。worker 把它居中放在黑底上，做高斯模糊（22 px）、压暗到 55%、四周加暗角（`sublime_backdrop`）。整镜伴随淡入和缓慢推近（`sb.backdropZoom`，从 1.12 倍推到 1.0）。
- 新文字样式 `sublime-red-brush`：马善政毛笔楷书，红色上下渐变加轻微做旧，暖白描边，柔和深色投影，在任何底色上都清楚。字像片头一样逐字打出。
- 台词里出现角色名字的句子不能当升华（`sublime.notWithNames`），由代码强制改回讲故事镜头。

### 重叠

- 取消"压在主卡片边缘前面"（`front`）的关系，模型给的 `front` 一律按"站在旁边"处理。
- 同一目标上方有多个飘浮元素时，左右排开；头顶空间不够时先缩小，还放不下就挂到目标的上角旁边，不再压到目标身上。
- 评分时只允许"盖在目标上"的元素和它自己的目标重叠，其他任何重叠都扣分。

### 实测（真实服务，`v11-survivor`，主题：什么是幸存者偏差，1 分半）

- **时长对了**：文案 416 字，配音 89.9 s，成片 92.7 s（上一支同样要求 90 s 却出了 138 s）。
- 30 镜：26 镜讲故事、4 镜升华。用 v11 的缓存重跑一次（`v11-calm`，`target/prod/survivor-v11-calm.mp4`）以后，9 镜带元素，每镜 1 个，抽帧检查没有重叠，排版居中。
- 升华 4 镜：虚化的靶子、奖杯、卷帘门、木门沉在黑底里，红字逐字打出，很清楚。其中一镜选了「章鱼哥翻白眼说这就是幸存者偏差」这种叙述句，"角色名不能当升华"这条规则就是为它加的。**这条规则和提示词的最后修改都还没有跑实测。**
