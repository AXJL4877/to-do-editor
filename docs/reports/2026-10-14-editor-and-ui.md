# 剪辑基础功能与原生 UI 改造报告

日期：2026-10-14

## 本次 UI 调整

根据最新反馈，界面统一改为直角、扁平化样式。按钮、输入框、媒体列表、轨道片段、面板和菜单取消圆角；背景使用中性深灰，蓝色用于当前工具和选中状态，橙色用于播放头。

- 媒体库与预览区之间增加左右拖拽分隔条，可调整媒体库宽度。
- 预览区与时间轴之间提供上下拖拽分隔条，可调整时间轴高度。
- 分隔条有把手、悬停高亮和缩放鼠标指针，双击恢复默认比例。
- 调整后的尺寸在本次程序运行期间保留；窗口缩小时会限制面板最小尺寸。
- 媒体库改为紧凑列表，展示类型、文件名、分辨率、时长和引用次数；长文件名自动截断。
- 工具按钮去掉成排描边，当前工具使用底部标记；时间轴标题与工具操作分行。
- 预览区分为标题、原生视频区域和状态栏，原生窗口只占视频区域，随面板调整位置与大小。
- 工程首页同步采用直角样式。

操作：拖动媒体库右侧分隔条调整宽度；拖动时间轴上方分隔条调整高度；双击对应分隔条复位。

## 此前完成的剪辑基础功能

- 删除选中的时间轴片段并保留空隙；支持波纹删除并闭合空隙。
- 轨道标题旁取消删除叉号。片段删除后清理多余的空轨道，至少保留一个视频轨和一个音频轨；锁定的轨道受到保护。
- 增加视频轨、音频轨；通过轨道右键菜单管理锁定、静音、显示和删除。
- 选择工具、剃刀工具、播放头处分割、片段移动、边缘裁切与吸附。
- 音视频关联选择、同步裁切与分割；支持撤销、重做、复制和粘贴。
- 媒体库搜索、引用计数、拖拽放入时间轴、双击追加、放到播放头。
- 批量导入和文件拖入，后台流式上传、探测媒体信息，逐项反馈成功或失败。
- 从媒体库移除素材与删除时间轴片段分别处理；原始媒体文件保留。
- 预览解码使用后台工作线程合并最新请求，释放播放头后补交最终定位，避免旧请求继续堆积。

常用快捷键：`V` 选择、`C` 剃刀、`Ctrl+K` 播放头分割、`Delete` 删除片段、`Shift+Delete` 波纹删除、`Ctrl+I` 导入、`Ctrl+S` 保存、`Ctrl+Z` 撤销。

## 文件组织

保持现有 Cargo workspace 和各 crate 的职责划分，独立模块使用对应文件夹。

| 位置 | 职责 |
| --- | --- |
| `crates/todo_ui/src/widgets/layout/` | 工作区面板尺寸、分隔条、原生预览布局与交互回归测试 |
| `crates/todo_ui/src/theme.rs` | 全局直角主题、颜色、按钮状态 |
| `crates/todo_ui/src/widgets/library/` | 媒体库搜索、列表、导入和拖拽 |
| `crates/todo_ui/src/widgets/timeline/` | 时间轴、轨道标题、片段绘制与交互 |
| `crates/todo_ui/src/widgets/shortcuts/` | 根据焦点分发快捷键 |
| `crates/todo_core/src/library/`、`tracks/`、`timeline/actions/` | 素材、轨道和剪辑操作规则 |
| `crates/todo_interaction/src/editor_session/`、`history/`、`clipboard/` | 编辑会话、历史和剪贴板 |
| `crates/todo_media/src/imports/` | 文件上传与媒体探测 |
| `crates/todo_app/src/media_bus.rs` | 后台任务和导入批次事件 |
| `docs/reports/` | 改动报告 |

视觉检查的临时渲染程序和输出集中在 Git 忽略的 `target/ui-review/`，未增加产品依赖。用户工程数据不用于生成测试样本；旧项目 JSON 兼容性测试改用内置固定样本，避免编辑工程后导致测试失败。

## 验证与当前状态

- `cargo test --workspace`：91 项 Rust 测试通过。
- `python -m unittest discover -s native/tests -v`：7 项原生预览测试通过。
- `cargo fmt --all -- --check`：通过。
- 使用实际 egui 绘制函数离屏渲染 1440×900、960×640 和面板极限比例，检查布局、截断与分隔条位置。此项没有验证真实视频画面在屏幕上的显示延迟。
- 布局回归覆盖左右拖拽、上下拖拽、最小尺寸限制、尺寸保持与双击复位。
- 仍有一条已有的 `ImportMedia` 未使用枚举分支警告。
- 标准程序构建在覆盖 `target/debug/todo_app.exe` 时遇到 Windows 拒绝访问，原因是旧编辑器进程正在运行。保存并关闭旧窗口后，在项目根目录运行 `./run.ps1`，即可重新构建并加载新界面。

当前覆盖基础剪辑工作流；特效、调色、字幕和完整导出流程仍属于后续开发范围。布局尺寸目前只在程序运行期间保存。
