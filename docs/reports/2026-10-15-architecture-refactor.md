# 架构拆分与编辑能力补全报告

完成日期：2026-10-15。文件夹分工见 [responsibilities.md](../architecture/responsibilities.md)。

## 实际改动

1. 新增 `todo_application`，从 interaction 和 app 收拢工程生命周期、编辑事务、历史、剪贴板、保存快照、播放和资源任务状态。定义 Action / Event / Effect，异步结果带操作与会话 ID。
2. 新增 `todo_storage`，工程创建、加载、保存、删除和 JSON 导入改为 Rust 本地存储。文档验证后通过临时文件和原子替换保存；删除保留到 `data/.trash`。返回与关闭等待成功回执，失败保留编辑内容。
3. core 整理为 `model/`、`edit/`、`query/`、`error.rs`。关联裁切、粘贴、来源范围、重叠、锁定和轨道兼容集中校验。删除旧兼容目录，保留稳定的 crate 根导出。错误使用类型，展示文案放到 presentation。
4. interaction 整理为 `input/`、`timeline/`、`presentation/`；删除原会话、历史和剪贴板的重复实现。UI 消费专用 ViewModel，菜单可用性和拖放预览由投影提供。
5. app 的 main 只启动应用；`runtime/` 执行帧循环和副作用；`adapters/` 负责线程、存储/媒体调用、预览、窗口和文件对话框。工程保存、媒体导入、波形/缩略图使用独立队列。
6. Node 保留媒体能力，移除工程 CRUD 和旧 TypeScript core。上传流式落盘，探测和缩略图异步执行；缩略图缓存随文件大小、修改时间和输出尺寸变化。启动检查改用 `/api/health`。

## 编辑行为

- 原生预览支持鼠标拖动位置，属性区支持 X/Y、缩放和重置。Clip 新增默认可省略的 transform，旧工程直接兼容。只改位置/缩放时重绘保留帧，不再次解码。
- 时间轴两端显示裁切手柄；拖动修改源入点/出点，Alt 拖动调整速率；属性区可输入时长。短片段左右手柄的绘制与命中保持一致。
- 片段移动同时考虑左右边吸附；裁切、剃刀、媒体拖放共用吸附计算。可吸附其他片段边缘、播放头和零点；关闭后仍按帧对齐。吸附时显示引导线。
- 手势统一进入事务：一次拖动一次撤销，Escape 取消。数值输入后转到原生预览时先提交上一事务，避免回退时长或位置。
- 保留删除选中素材、保留空隙/波纹删除、关联音视频、空轨清理和至少一条视频/音频轨规则。

## 当前边界

预览仍呈现单个命中的视频片段，尚未成为多层合成器。完整导出、关键帧/转场、代理、多序列、自动保存与崩溃恢复仍需后续实现。本轮包含自动化控件事件和原生进程回归，未完成整套人工桌面视觉验收或大型项目压力测试。
