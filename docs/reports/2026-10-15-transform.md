# Transform 架构与预览操控

## 领域模型

变换数据从 Clip 文件抽离到 `todo_core/src/transform/`：

| 文件 | 职责 |
| --- | --- |
| `model.rs` | Transform 模型、默认值与合法性检查 |
| `geometry.rs` | 素材适配画布后的位置、宽高和边界计算 |
| `mod.rs` | 统一导出；ClipTransform 保留为兼容别名 |
| `edit/transform.rs` | SetTransform 编辑操作，检查轨道锁定并修改指定片段 |

参数定义：

| 字段 | 含义 | 默认值 |
| --- | --- | --- |
| `x`、`y` | 相对画布宽高的中心偏移；例如 x=0.1 向右移动画布宽度的 10% | 0 |
| `scale` | 同时作用于宽高的缩放倍率 | 1 |
| `scaleX`、`scaleY` | 在统一缩放基础上，分别调整宽度和高度 | 1 |
| `opacity` | 不透明度；0 完全透明，1 完全不透明 | 1 |

位置、缩放和透明度必须为有限值；各缩放倍率及有效乘积必须为正，透明度范围 0..=1。旧工程只包含 x/y/scale 时，新字段使用默认值；没有 transform 时仍居中显示、保持原大小和不透明。默认 Transform 在 JSON 中可以省略。

## 操作与分层

- 右侧属性栏新增横向缩放、纵向缩放、不透明度；保留位置、统一缩放和重置，数值操作走已有编辑事务。
- 预览内点击可见元素可选择并移动。选中后显示矩形和八个手柄，拖边缘单独改变宽高，拖角等比缩放；对侧边/角保持不动，缩至最小尺寸停止，防止翻转。
- 一个完整手势对应一次撤销，Escape 取消，轨道锁定时不能修改。透明度为 0 的已选元素仍保留控制框，便于找回。
- `todo_interaction/src/transform/` 管理命中与手势；`input/preview.rs` 只协调选择和事务；属性输入/投影仍归类在 `inspector/`。
- `todo_ui/src/widgets/inspector/transform/` 绘制参数控件；选中元素不会改变节目画布大小，查看参数不会擅自钳制已保存的合法值。
- application 复用 SetTransform、历史和预览更新计划；app 仅将值映射到原生传输类型。
- 控制框不保存进工程。interaction 根据当前实际预览尺寸投影，app 在处理本帧视口输入后转发，窗口和面板调整不会产生历史记录。
- 原生预览应用位置、宽高、不透明度和控制框时只重绘保留帧，不重新请求解码；旧三参数协议继续兼容。
- 原生变换数学、显示几何、控制框与着色器集中在 `native/src/transform/`，没有把 GPU、窗口或手柄逻辑放入 core。
- 解码器回传考虑非方形像素和可见区域的实际显示比例。每次素材请求携带代次，app 忽略过期回执；interaction 临时缓存当前素材比例，命中、控制框与缩放使用同一计算。旧工程无需新增元数据即可校正非方形像素素材。

## 验证范围

覆盖旧/新 JSON、非法数值、宽高比与二维边界、透明元素几何、剪辑操作后参数保留、本地保存重载、属性参数独立修改、查看属性不自动修改数据、八方向手柄、对侧固定、极小尺寸命中、撤销/重做、Escape 和锁定，以及原生协议、渲染和已有拖动回归。另有非方形像素素材及过期显示比例回执的回归检查。

当前渲染仍是单个视频片段的预览，不透明度与黑色预览背景混合；本轮没有引入多层视频合成、旋转、关键帧或新的序列分辨率模型。没有尺寸元数据的素材会保留参数，但不会猜测并绘制可能错位的缩放手柄。
