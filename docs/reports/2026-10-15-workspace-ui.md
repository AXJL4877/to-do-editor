# 工作区与轨道操作调整

## 改动

- 选择工具和剃刀使用矢量图标，悬停显示工具名称及 V/C 快捷键。
- 移除时间线工具栏的切分播放头、删除、波纹删除和全局添加轨道按钮。Ctrl+K、Delete、Shift+Delete 与片段右键菜单仍可使用。
- 每条轨道标题左侧增加“＋”。根据所点击轨道的 ID，在它正下方插入同类型空轨道，保留现有内容和顺序，支持撤销/重做。
- “联动”改为“链接选择”，提示说明用于一起选择已链接片段，例如同一素材的音视频。关闭开关可单独选择，不会解除已有链接。
- 播放/暂停从顶部工具栏移到节目预览下方，和时码、FPS 放在同一控制区。
- 属性栏成为节目窗右侧始终占位的独立板块。未选择时显示提示，选中后显示文件名、时长、起点、源入点、速率、X/Y、缩放和重置画面。属性区支持独立宽度调整、双击恢复和垂直滚动。
- 选择和取消选择不再改变节目预览大小；属性输入后切换到另一片段，会先提交上一字段，防止后续操作覆盖尚未提交的修改。

## 文件分工

| 目录 | 内容 |
| --- | --- |
| `todo_core/src/edit/` | 插入轨道的完整规则与语义命令 |
| `todo_application` | 复用编辑事务和历史，验证新增轨道可一次撤销/重做 |
| `todo_interaction/src/inspector/` | 新的属性功能目录：片段显示投影、时长/位置/缩放输入翻译 |
| `todo_ui/src/widgets/inspector/` | 独立属性面板及片段字段控件 |
| `todo_ui/src/widgets/controls/` | 公用数值编辑事务辅助，供工具栏与属性栏共用 |
| `todo_ui/src/widgets/layout/` | 媒体库、节目预览、属性栏、时间线的布局和分隔条 |
| `todo_ui/src/widgets/timeline/` | 工具图标和每行轨道左侧的新增入口 |
| `todo_ui/src/widgets/monitor.rs` | 节目画布与下方播放控制 |
