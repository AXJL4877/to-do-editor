# 共用编辑能力层

用户范围：先实现供内置 AI 和外部 AI 共用的编辑能力，并优化阻碍调用的现有流程。本轮不实现模型连接、聊天 UI、HTTP、MCP 或视频内容分析。

## 边界

- `todo_application::control` 提供可序列化的请求、快照、编辑操作、回执和错误。
- `Workspace::control_context()` 获取当前会话快照；`Workspace::control(request)` 在持有工作区的线程执行，返回 `ControlOutcome { response, update }`。
- 调用方使用现有 app 的 Effect 执行/回传流程处理 `update`。本层没有网络、文件系统、线程或 UI 依赖。
- `todo_core` 继续负责所有编辑约束。新增源区间入轨命令，并统一关联音视频切开行为。
- 关联切开通过新的 SplitLinked 命令提供；原 Split 保留显式片段选择语义，保持手工关闭关联选择时的既有行为。
- 当前工作区包含尚未提交的 Rust 迁移，直接基于这些文件实现；不创建缺少这些文件的 worktree，不打包或提交用户已有修改。

## 请求与读取

- 协议版本为 1；字段 camelCase，命令类型 snake_case，拒绝未知请求字段。
- 请求包含 `requestId`、`sessionId`、可选 `expectedRevision` 和命令。所有修改必须提供修订号。
- 会话 ID 来自 Workspace generation，工程重新打开后变更。revision 为独立运行时计数，不是工程文档 version。
- revision 在工程内容实际变化时递增，人工编辑、导入、撤销、重做及手势取消均覆盖；播放头和保存回执不改变内容修订号。
- 快照返回工程、名称、播放头、revision、dirty、撤销/重做、忙状态及导入任务；不包含 interaction 持有的选择/面板状态。

## 编辑

- 支持整段或源区间入轨、移动、裁切、切开、删除、添加轨道、画面变换。
- 时间均为秒，源时间与时间轴时间使用不同字段；不隐式应用鼠标吸附。core 校验至少一个工程帧的片段时长。
- `ClipRef::Id` 引用现有片段；`ClipRef::Created { step }` 引用同一批次之前步骤生成的片段，step 为从 0 开始的索引。
- 一组编辑在副本上顺序执行，成功后提交一次并产生一条历史；任何步骤失败均不修改工程、预览和历史。活动手势、导入、关闭确认或工程切换期间拒绝修改。
- 每步返回生成、修改、删除的片段快照（含轨道 ID），以及切开前后 ID 映射。无变化明确返回 changed=false。
- dryRun 执行同样校验但不提交。试运行生成的 ID 仅供预览，正式调用重新生成。
- undo/redo 使用现有历史，并返回内容变化情况。

## 导入

- 共用接口仅导入素材库。现有 UI 导入继续组合“导入 + 自动追加”。
- 返回任务 ID，通过查询获取 running/completed/completed_with_errors/failed 状态、完成数、素材 ID 和错误。
- 导入仍使用现有 MediaTask、worker 和 Ticket，会话切换后的旧回执被忽略。
- 每个成功素材独立登记并沿用现有保存流程。文件任务不在时间轴事务中回滚，undo 不删除磁盘文件。
- worker 无法接收任务时通过 ImportAborted 结束任务，避免一直处于 importing。
- 任务使用本次 EditorUpdate.error，而非遗留 Status。非法元数据拒绝登记，合法素材自动追加失败仍计为成功登记并报告追加错误。

## 重试与错误

- 修改请求按会话和 requestId 去重；同 ID 同内容返回原回执且不重发副作用，同 ID 不同内容返回 request_id_conflict。
- 最近 128 个修改回执可重放；过期 ID 保留标记并返回 request_expired，不能重新执行。
- 只缓存修改请求，读取查询每次返回实时状态。每会话最多保留 16384 个请求标记，达到限制拒绝新修改。
- 参数、会话、修订号、忙状态及领域错误都有结构化 code、message，领域错误保留对象 ID 和失败步骤索引。
- 导入最多 256 个路径，批次最多 128 步，requestId 为 1..128 字节非空字符串。

## 验收

1. 导入 A 到库，时间轴无新增片段；任务完成后读到素材 ID。
2. 同一批次将源 3..8 秒放在时间轴 10 秒，再在 12 秒切开，关联音视频得到对应的两段；一次 undo 恢复入轨前状态。
3. 后续步骤失败时工程和历史完全不变；锁定、越界、旧版本、活动手势、重试均有测试。
4. 现有人工拖拽、导入自动追加、预览刷新及保存用例通过回归。
