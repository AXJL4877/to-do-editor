# 基础剪辑工作流实现计划

> **For agentic workers:** 使用 test-driven-development；独立领域按 dispatching-parallel-agents 分工，最后统一验证和独立审查。

**Goal:** 在现有 Rust/egui 编辑器中实现可连贯使用的媒体库、轨道管理、片段编辑和撤销重做。

**Architecture:** 保留 core → interaction → UI → app 的现有分层；core 提供纯数据编辑，interaction 管理选择、历史、拖动与预览同步，UI 只产生意图，app 负责文件和后台任务。

**Tech Stack:** Rust、egui/eframe 0.31、现有 Node 媒体 API、现有 C++ 预览引擎。

**Spec:** 本文“行为约定”；用户已要求直接实现，保留当前未提交迁移与上一轮预览优化，不创建替代工程、不提交整份迁移。

## 行为约定

- 轨道标题不放直接删除叉号；Delete 删除选中的片段，保留空隙；Shift+Delete 波纹删除。
- 删除片段后清理多余未锁定空轨，至少保留一个 Video 和一个 Audio；新建空轨暂时保留以便放入素材。
- 轨道菜单独立提供增加、删除、锁定与静音/显示控制；锁定轨道上的编辑不生效。
- 导入进入媒体库，不隐式插入时间轴；支持多文件导入、媒体库检索、放入播放头/追加、拖放到空白轨道区域。
- 时间轴支持选择/多选、关联音视频选择、剃刀、普通/波纹删除、移动、边缘修剪、复制粘贴、帧吸附、撤销重做。
- 新放入的音视频片段用可选 linkId 关联；兼容旧 JSON，没有 linkId 的旧片段保持独立。
- 媒体库移除仅修改工程引用，不删除磁盘源文件；被使用的素材必须显式选择“连同片段移除”，锁定引用阻止移除。
- 预览保留上一轮最新请求覆盖与过期解码退出；保存/重载保留全部编辑。
- 本轮定位基础剪辑工作流；完整特效、字幕、调色、多序列、成片导出不在这一轮实现范围，报告明确说明。

## Global Constraints

- 保留 crates、native、backend 的项目结构；独立职责新建模块目录。
- 不覆盖或清理用户已有改动与素材；构建/测试临时文件放 target 或 native/build。
- 不新增产品依赖；不改变已有媒体本地存储约定。

## Review Focus

- 锁定轨道、关联片段的局部失败不能留下半次编辑。
- 波纹删除不能造成负时间、覆盖或其他轨道音画失步。
- 连续拖动只生成一次可撤销操作；取消拖动恢复起点。
- 导入错误、取消、多文件部分失败不能卡住 busy 状态，导入不阻塞 UI 读取大文件。
- 导入与删除后媒体库、时间轴、预览、保存和重载保持一致。
