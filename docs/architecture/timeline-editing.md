# 时间轴移动与吸附

## 用户行为

- 靠近其他片段边界或播放头 8 像素以内时吸附。吸附保留目标的精确时间，不再次取整到帧，因此带小数时长的素材也能贴齐。
- 没有吸附目标或关闭吸附时，主片段位置仍按工程帧率对齐。
- 工作区时长是独立的合成设置。例如设置为 300 秒后，导入 600 秒素材不会修改这个设置；素材库和时间轴片段保留完整 600 秒内容。
- 播放和播放头结束仍以工作区时长为界；时间轴横向编辑范围取工作区结束与片段实际结束位置的较大值，超出部分可以滚动查看和编辑。超出区域会在界面中加暗，并显示“工作区结束”标记。
- 所有选中片段使用同一时间位移，最早片段最多移动到零点；其余片段的间距、源偏移、速率与 linkId 保持不变。
- 点击拖动的片段是本次主片段，即使此前已通过关联音频或多选选中了它。
- 移动区间有冲突时，优先目标轨道，其次同类型空闲轨道，最后创建轨道。原轨道无冲突的关联成员继续保留原轨道。
- 音频和音效可显式互相移动；自动寻找空闲轨道时保持目标的具体类型，普通音频不会自动进入音效轨道。
- 精确相邻不算重叠。原来同一源轨道的选中片段作为一组分配，逐个检查实际区间，不把它们之间的空隙视为占用。
- 源轨道或显式目标轨道锁定时，整个移动失败；不会只移动关联对象的一半。
- 一次拖动只记录一次撤销，新增轨道也随撤销、重做或 Escape 取消一起恢复。

例如，A 的画面与音频位于 0..4 秒，B 的画面与音频位于 6..10 秒。将 B 拖到 2..6 秒后，A 保留原位置；B 的画面和音频分别进入可用的视频、音频轨道，均从 2 秒开始。已有空闲轨道可复用，否则新增所需轨道。将 B 拖到 4 秒恰好相接时，继续使用原轨道。

## 职责划分

Alt/Ctrl + 滚轮缩放以鼠标下的时间为锚点。interaction 计算新倍率和滚动偏移，UI 用同一个 ScrollArea 状态 ID 在下一帧应用偏移。每次有效倍率变化都同步，不以绝对像素密度阈值过滤长工程的小幅变化。到达左右滚动边界或缩放极限时服从边界限制。

| 文件 | 职责 |
| --- | --- |
| todo_interaction/src/timeline/snapping.rs | 指针时间、精确边界吸附、整组零点限制 |
| todo_interaction/src/timeline/controller.rs | 拖动起点、滚动差值、主片段、显示行与轨道 ID 的转换 |
| todo_core/src/edit/move_clips.rs | 校验与原子移动，按源轨道分组，保持时间与源区间 |
| todo_core/src/edit/track_space.rs | 素材入轨和片段移动共用的空闲检查与轨道分配 |
| todo_core/src/edit/tracks.rs | 创建轨道、唯一 ID 与视频/音频/音效分区 |
| todo_application/src/editor/commands.rs | 手势期间的基线执行、提交、取消、撤销和重做 |

拖动每次更新均从手势开始时的工程计算，不在前一帧结果上累加位移。界面行索引根据当前显示工程转为轨道 ID，避免新增视频轨道后音频行错位。若鼠标明确指向手势中新建的轨道，application 将它作为空目标加入本次执行副本，保持指向的新轨道，即使原轨道已空闲；原始撤销基线保持不变。其余按需创建的轨道由分配器重新计算。

## 接口与数据兼容

继续使用 `EditCommand::MoveClips`；共用 AI 控制层沿用相同策略，不增加第二套移动实现。片段 ID、关联 ID 和工程文档结构不变。控制回执报告实际轨道及新增轨道 ID。
