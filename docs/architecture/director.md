# 内置 Agent：导演

更新：2026-10-18。代码：`todo_application::director`（状态机、提示词、解析）、`todo_application::control::review`（规则审片和检查单）、`todo_app::adapters::director`（接入真实服务的执行器）、`todo_app::runtime::agent`（面板）。

## 1. 流程

```text
内置 Agent（编辑器）的一句话
  └─ 规划 ControlEdit（可带换图）→ dry-run → 一个撤销步 → 规则审片 → 渲染几帧给用户看

模板成片（右侧“新建成片”）
  └─ 用户显式选择扩展和参数 → 扩展配方成片，等成片入轨
       → 规则审片（control::review::inspect，确定性，不花钱，只报告）
       → 检查单：风格要检查的每张画面取一帧停稳的节目帧，审片员只回答配方里的是非题
       → 有答「no」的画面：成片用同一个分镜描述重画这几张（新 variant），原位替换
       → 只复查重画过的画面，最多 2 轮
  → 审批卡：没通过的检查项和规则问题 + 节目帧 → 用户通过后导出，或者继续说要改什么
```

内置 Agent 不会从已安装扩展中猜模板，也不会自动启动某个风格。扩展生产由生产面板显式选择；新增或更新模板不会改变编辑 Agent 的行为。

## 2. 审片员只做选择

v5 证明了自由审片不可靠：审片员把片头故意做的灰色重影当成缺陷，修改模型随后删掉了标题文字、换掉了标题卡。所以现在：

- 审片员不写问题描述，也不提修改建议。它只对每张画面逐题回答 `yes`、`no` 或 `unsure`。题目是风格配方里固定的检查单。
- 只有明确的 `no` 才算没通过；`unsure`、缺答、回答无法解析都算通过。审片员拿不准时什么都不会发生。
- 没通过时的动作是固定的：成片用原来的分镜描述再画一张（换一个 variant），通过成片管线原有的 key/rev 原位替换。时间、转场、动效都由配方决定，不受影响。
- 只检查配方 `checked` 列出的画面（海绵宝宝风格是 `beat/*/card`）。片头、片尾、背景、字幕、配音和音乐不在检查范围内，也就不会被修改。
- 审片员的回答从不变成编辑。审片员判断错了，最坏结果是多花一张图的钱，不会损坏成片。

## 3. 随机性在哪里、怎么收住

| 环节 | 由谁决定 | 约束 |
| --- | --- | --- |
| 文案 | 模型 | 字数按目标时长计算；句子长度、角色、开头和结尾有硬性规则 |
| 分镜 | 模型 | 只能选配方里的镜头和转场。句子必须连续、完整覆盖，节拍时长有上下限。不合规会带着错误清单打回一次，仍不合规就按确定性规则分组 |
| 版式、动效、字幕、转场、BGM | 配方（`recipe.json`） | 确定性编排，没有模型参与 |
| 审片 | 规则 + 检查单 | 规则清单是确定的，只报告。检查单是封闭的是非题 |
| 修正 | 固定动作 | 没通过的画面用同一描述重画，最多 2 轮；仍没通过的交给用户 |
| 用户要求的编辑 | 模型 | 只能用 `ControlEdit`，先 dry-run；被拒绝时给模型一次修正机会。换图可以从风格素材库选（`library`），或者生成（`draw`），一次最多 3 张，和编辑合成一个撤销步 |

导演本身不访问网络、不读写文件。它只返回 `Call`（问模型、渲染、成片、重跑成片、应用编辑），再接收 `Input`（结果）。所以编辑器、命令行和单元测试跑的是同一套流程。

## 4. 风格扩展需要提供什么

- `extension.json`：参数（导演会把 `id（label，可选值）` 交给模型去填，重画参数除外）。文案可以设为 `"optional": true`，没有文案时由扩展按主题自己写。
- `recipe.json` → `review`：
  - 规则阈值：`safeArea`、`subtitleBaseline`、`subtitleMaxChars`、`maxOverlap`、`maxHold`；字幕样式取自 `text.subtitle.style`。
  - `checks`：检查单，格式为 `[{id, question}]`，问题要写成「是」为好的形式。
  - `checked`：要检查的画面的成片 key，`*` 匹配任意字符。
  - `lines`：台词（字幕）的 key 前缀。每张画面会附上同时段的台词。
  - `redraw`：重画参数的 id。导演把它设为 `key:variant,…`，扩展对这些 key 用同一描述、以新 variant 重画，其它请求不变（从任务日志直接取回，不重复计费）。重画后的文件名和 rev 必须变化，才会原位替换。
- 可选 `motions/*.json`：风格自带的动效预设。
- 可选 `assets/library/library.json`：风格素材库，格式为 `[{id, kind: cast|prop|plate, name, desc, file}]`。用户要求换图时，导演从这里挑。

## 5. 运行

- 编辑器：在工具栏打开「内置 Agent」，直接说要怎么修改当前工程。过程会在面板里实时显示（导演 / 审片 / 修改），结束时出现审批卡。模板成片请先在右侧「新建成片」里选择扩展。
- 命令行（真实服务，会产生费用）：

```text
cargo run -p todo_app --example direct -- <工程名> "用海绵宝宝风格做一支 30 秒的视频，讲什么是沉没成本" --fresh --export target/prod/out.mp4
```

外部 Agent 仍然可以用 [Agent Bridge](agent-bridge.md) 的 JSONL 协议，走同一套 `ControlEdit` 和节目帧渲染。
